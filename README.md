# Household Balance Forecast — GitHub Pages build

This folder is ready for GitHub Pages.

After publishing, open the site in Safari on iPhone, tap Share, then Add to Home Screen.

The app stores its data locally on that device. Use Export periodically as a backup.
This static version does not directly connect to Plaid.

## August plan update
- Income display name is now editable in Settings and defaults to `Salary`.
- Employer-specific wording was removed from the app source.
- The $475 rent catch-up is removed because it has been paid.
- Landlord late fee is removed because there is no fee.
- One Regional Finance payment is removed because it was forgiven; only the next scheduled Regional Finance payment remains.
- Existing browser data is migrated automatically when the new version loads.
